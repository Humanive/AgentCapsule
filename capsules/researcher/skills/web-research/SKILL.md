# Web research

1. Define the question, date boundaries, and evidence needed.
2. Use available search/browser tools to locate primary sources.
3. Read original pages; record URLs, dates, and directly supported claims.
4. Compare independent sources where material claims conflict.
5. If search tools are unavailable, explicitly report that limitation.
6. Consult references/source-notes.md for the evidence note format.
